# План: Система критических ударов

## Обзор
Добавить кастомную систему критических ударов, которая заменит ванильную Minecraft-логику критов.

## Архитектура

### 1. Новые файлы

#### `src/main/java/com/auranite/abloom/AbloomAttributes.java`
Реестр кастомных атрибутов через `DeferredRegister`:
- `CRIT_CHANCE` — шанс крита (по умолчанию 0.05 = 5%)
- `CRIT_DAMAGE` — дополнительный множитель крита (по умолчанию 0.5 = 50%)

Использует `Attribute` с `StringAttributeModifier` и базовым значением (`baseValue`).
Регистрация через `modEventBus` в `AbloomMod` конструкторе.

#### `src/main/java/com/auranite/abloom/CriticalMixin.java`
Mixin на `LivingEntity` для блокировки ванильных критов:
- Перехватывает `calculateCRITDMG(float damage, DamageSource source)` через `@ModifyReturnValue`
- Возвращает `damage` без изменения (отключает vanilla crit multiplier)
- Ванильная логика: `damage * (1.0F + random.nextFloat() * 0.5F)` — умножает на 1.0-1.5
- Наша система полностью контролирует крит через `ElementDamageHandler`

#### `src/main/resources/abloom.mixins.json`
Добавить `"CriticalMixin"` в массив `mixins`.

#### `ElementDamageHandler.java`
Добавить логику крита в `doProcessLivingHurt()`:

```java
// После вычисления finalDamage, но до отображения:
boolean isCrit = checkAndApplyCrit(attacker, target, source, currentDamage);
if (canShowDamage(target)) spawnDamageNumber(target, finalDamage, type, isCrit);
```

Метод `checkAndApplyCrit()`:
1. Получить `critChance` из атрибутов атакующего (если есть)
2. Получить `critChance` из оружия атакующего (компонент + регистр)
3. Суммировать: `totalCritChance = entityCritChance + weaponCritChance` (clamp 0-1)
4. `random.nextFloat() < totalCritChance` → крит
5. Если крит: `finalDamage *= (1.0f + totalCritDamage)`
6. Вернуть флаг крита

## Детали реализации

### Вычисление крит шанса
```
totalCritChance = entityCritChance + weaponCritChance
clamped to [0.0, 1.0]

totalCritDamage = entityCritDamage + weaponCritDamage
clamped to [0.0, 10.0] (макс 1000% доп. урона)

if (random.nextFloat() < totalCritChance) {
    finalDamage *= (1.0f + totalCritDamage);  // 50% = умножение на 1.5
    isCrit = true;
}
```

**Важно:** Крит система применяется ко ВСЕМ типам урона, не только элементальному.

### Источник данных (приоритет)
1. **Forge атрибуты сущности** — глобальные модификаторы (эффекты, бусты)
2. **Оружие (компонент)** — локальные модификаторы
3. **Datapack (реестр)** — базовые значения для предметов
4. **Дефолты** — 5% шанс, 50% урон

### Пример JSON для datapack
```json
{
    "item": "minecraft:diamond_sword",
    "element": "FIRE",
    "accumulation_multiplier": 1.5,
    "crit_chance": 0.15,
    "crit_damage": 0.8
}
```

### API для модов
```java
// Получить крит-шанс для сущности с оружием
public static float getCritChance(LivingEntity attacker)
public static float getCritDamage(LivingEntity attacker)
public static boolean isCrit(LivingEntity attacker)

// Регистрация крит-параметров для оружия
public static void registerWeaponCrit(ResourceLocation itemRL, float critChance, float critDamage)
```

## Порядок реализации
1. `AbloomAttributes.java` — регистрация Forge атрибутов (CRIT_CHANCE, CRIT_DAMAGE)
2. `CriticalMixin.java` + `abloom.mixins.json` — блокировка ванильных критов (calculateCRITDMG)
3. `ElementalWeaponData.java` — добавление полей critChance/critDamage
4. `ElementalWeaponProvider.java` — парсинг полей из JSON
5. `ElementalWeaponComponent.java` — хранение в DataComponent
6. `ElementalWeaponRegistry.java` — хранение в реестре + методы getCritChance/CritDamage
7. `ElementDamageHandler.java` — логика крита для ВСЕХ типов урона
8. `ElementDamageDisplayManager.java` — отображение "!!" для критов
9. `AbloomMod.java` — регистрация атрибутов
10. Сборка и проверка

## Верификация
1. `./gradlew build` — успешная сборка
2. Базовый крит шанс 5% работает для всех сущностей
3. Datapack крит-параметры применяются к оружию
4. Атрибуты сущности модифицируют крит шанс/урон
5. Криты отображают "!!" после урона
6. Ванильные криты отключены (нет случайных 1.0-1.5x множитетей без нашей системы)
